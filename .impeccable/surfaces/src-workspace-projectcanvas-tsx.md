## Scope

Saved canvas workspace for designers and studio teams. Mode: Operate. The workspace opens from the local or cloud project list; the scripted sample is a separate route.

## Direction

The Crit Wall remains a light canvas inside a graphite shell. Moodboard shows reference and file prints, while Node map reveals the same board's connections. Preserving one document makes it possible to switch without rearranging material. Thin graphite lines carry relationships. Colored dots retain their state meanings. Native images and sticky notes keep their media.

## Interaction

The top bar holds the two views, a connection control in Node map, background and grid options, panel toggles, and focus mode. Link and file cards use recognizable source marks or a generic type icon beside text. On compact screens, the board opens with panels closed. The top header contains the project identity and options. The bottom dock keeps canvas view and panel controls within reach. Layers and Sources share a searchable left rail on desktop and an expandable lower dock on touch layouts. Add and Assistant occupy the other rail on desktop and use the same lower dock on compact screens. The optional canvas guide is opened from the Help control. Background and view choices persist separately from the board so changing the view cannot rewrite canvas records.
